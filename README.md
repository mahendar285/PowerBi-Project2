# PowerBi-Project2

Chocolate Sales Dashboard built with Power BI to analyze sales performance, profit trends, and product performance.

## Project Overview
This dashboard transforms raw chocolate sales data into business insights by focusing on:
- Top revenue-generating products
- Regional sales performance patterns
- Salesperson contribution to overall business growth

## What was practiced
- Data cleaning and preparation
- Data modeling
- DAX calculations
- Interactive visualization design in Power BI
